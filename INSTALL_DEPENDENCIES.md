# Email Enhancement Dependencies Installation

## Required Dependencies

Run the following command to install the new dependencies:

```bash
npm install react-quill@^2.0.0 emoji-picker-react@^4.11.1
```

## What's New

### 1. Rich Text Editor (ReactQuill)
- **Bold, Italic, Underline** formatting
- **Text alignment** (Left, Center, Right)
- **Image embedding** support
- **Professional HTML output**

### 2. Emoji Picker
- **Full emoji support** with categories
- **Search functionality**
- **Skin tone variations**
- **Click-outside to close**

### 3. File Upload System
- **File size validation** (5MB limit)
- **File type validation**
- **Image compression** and optimization
- **Drag & drop support** (coming soon)

### 4. Enhanced Email Templates
- **Professional HTML design**
- **Mobile responsive**
- **Better typography**
- **Branded styling**

## Usage

1. **Install dependencies**: `npm install`
2. **Start development**: `npm run dev`
3. **Open email composer** on accessed leads page
4. **Use toolbar buttons** for formatting
5. **Click emoji button** to add emojis
6. **Upload images** directly into email content
7. **Attach files** using paperclip button
